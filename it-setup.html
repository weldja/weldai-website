IT setup guide

For IT staff and IT support companies · Updated November 2026

Weld AI is a document question-answering system that runs entirely on one Windows PC. The language model, the search index and the documents all stay on that machine. This guide covers how it is built, what to prepare, and what you can verify for yourself.

Start with the system check. The free system check script confirms the PC meets the requirements below. It makes no changes and no network connections.

How it is built

Weld AI runs as a small set of Docker containers under Docker Desktop with the WSL2 backend.

ComponentWhat it does
Web proxy (nginx)Serves the web interface over HTTPS. The only container with published ports.
API and workerSign-in, search, and reading and indexing documents.
Database (PostgreSQL with pgvector)Users, groups, document text and the search index.
Model runtime (Ollama)Runs the language model and the search model locally, on the graphics card or the processor.
  • Models: the answer model is Qwen3 4B (Apache 2.0 licence) and the search model is bge-m3 (MIT licence). Both ship inside the installation bundle. Nothing is downloaded from a model site at install time or afterwards.
  • Network isolation: the API, worker, database and model runtime sit on an internal Docker network with no route to the internet. Only nginx is reachable, on ports 80 and 443.
  • No telemetry: Weld AI collects no usage data and has no update check, licence server or crash reporting. Telemetry is switched off in every component that has it.
  • Tested: every release runs an automated check that the containers cannot reach the internet.
  • Logs: written locally only. They do not contain document text or the text of questions.

The PC needs to stay on and awake during working hours, so turn off sleep and hibernation. A desktop or small workstation suits this better than someone's laptop.

What to prepare before the install call

1. An Administrator account

Someone who can approve Administrator prompts needs to be at the PC during the call.

2. WSL2

In PowerShell as Administrator, run the following and restart when asked:

wsl --install

After the restart, confirm it reports Default Version: 2:

wsl --status

3. A current NVIDIA driver, if the PC has an NVIDIA card

Install the latest driver from NVIDIA. Current drivers include GPU support for WSL2, which is how the containers reach the card. Confirm the card is visible:

nvidia-smi

4. A fixed address and a name

If staff will use Weld AI from their own PCs, give this PC a static IP address or a DHCP reservation, and ideally a DNS name such as weldai.yourfirm.local.

5. Firewall rules, for more than one user

Allow inbound TCP 80 and 443 from the office network:

New-NetFirewallRule -DisplayName "Weld AI HTTP" -Direction Inbound -Protocol TCP -LocalPort 80 -Action Allow
New-NetFirewallRule -DisplayName "Weld AI HTTPS" -Direction Inbound -Protocol TCP -LocalPort 443 -Action Allow

HTTP redirects to HTTPS. If 80 or 443 is already in use on the PC, Weld AI can listen on other ports.

6. A TLS certificate (optional)

If you have an internal certificate authority, issue a certificate for the PC's DNS name. Without one, the installer creates a self-signed certificate and browsers show a warning the first time.

That is all. On the call I install Docker Desktop, load the Weld AI bundle, enable the graphics card, create the first administrator account and connect your document folders.

Internet access

Weld AI makes no outbound connections. The internet is used on install day only, for the screen-share call and to download Docker Desktop.

Windows and Docker Desktop are separate products with their own update checks. If your policy is that nothing at all leaves this PC, block its outbound traffic at your firewall once the install is finished. Weld AI carries on working. You would then apply Windows and Docker updates on your own schedule.

Docker Desktop is free for small businesses. At the time of writing, Docker requires a paid subscription only for organisations with more than 250 employees or more than US$10 million in annual revenue. Check Docker's current terms if you are close to either limit.

Accounts and access control

  • Local accounts: each person has their own sign-in. Passwords are hashed with Argon2id, the minimum length is 12 characters by default, and an account locks for 5 minutes after 5 wrong attempts. There is no default account or password.
  • Active Directory or LDAP: staff can sign in with their Windows account. You will need the LDAPS address, the CA certificate that signed the directory's certificate, a read-only service account and the OUs that hold staff and groups. The connection is always encrypted and the certificate is always checked.
  • Groups: a document is visible to its uploader, to administrators and to the groups it is shared with. The rule is enforced inside the database query, so a person outside a group cannot retrieve its text through search or through an answer.
  • Sessions: held on the PC, with HttpOnly, Secure, SameSite=Strict cookies.

Document folders

Weld AI can index up to three folders in place, read-only. It checks them every five minutes for new, changed and deleted files, and it never modifies, copies or moves a file. Staff can also upload individual documents in the browser.

Folder permissions are not inherited. Weld AI does not read Windows (NTFS) permissions. Each indexed folder is assigned to one or more Weld AI groups, and everyone in those groups can search everything in it. Keep folders with different audiences, such as HR or board papers, as separate folders with their own groups, or exclude them.
Where the documents areSupported
Local drive on the PCYes
USB or external driveYes, if it stays connected
OneDrive or SharePoint synced folderYes, set to "Always keep on this device"
Mapped drive or UNC pathNot directly. Docker Desktop cannot mount network paths, so I set up a scheduled robocopy mirror to a local folder.

Formats: PDF, Word, PowerPoint, Excel, CSV, HTML, text and Markdown; scanned PDFs and PNG, JPEG and TIFF images through OCR that runs on the PC; and Outlook .msg emails, including supported attachments. Password-protected PDFs cannot be read.

Backups and upgrades

  • Backups: the bundle includes a backup script. A backup holds the database (users, groups and the search index), uploaded files and the configuration. It contains the database password and the TLS private key, so store it as securely as the PC itself, and keep a copy somewhere other than the PC.
  • Your documents: files in indexed folders are not part of the Weld AI backup. Carry on backing them up as you do today.
  • Upgrades: a new version arrives as a new bundle. The upgrade script takes a backup first and the previous version stays on the PC for rollback.
